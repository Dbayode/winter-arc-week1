# 90-Day DevOps Winter Arc — Week 1

## Linux, Networking and Git/GitHub

This repository documents Week 1 of my 90-Day DevOps Winter Arc
learning journey with the DevOps Universe community.

The focus is on developing practical Linux administration,
networking, troubleshooting, automation and Git skills.

## Project Objectives

- Understand the Linux filesystem and shell.
- Manage Linux users, groups and permissions.
- Write reusable Bash scripts.
- Manage processes and systemd services.
- Understand networking and SSH.
- Configure Nginx as a reverse proxy.
- Monitor storage and troubleshoot Linux systems.
- Use Git and GitHub for version control.

## Learning Roadmap

| Day | Topic | Project |

## Learning Method

Each day follows this process:

1. Understand the concepts.
2. Practise the commands.
3. Complete a practical project.
4. Troubleshoot problems.
5. Verify the results.
6. Document the learning.

## Goal

Build practical DevOps skills and demonstrate my progress
through reproducible projects and technical documentation.
